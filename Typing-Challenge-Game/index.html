INSTRUCTIONS

How to play

01
Bubbles

Type the letters in the rising bubbles. Correct = +10 points. Wrong keys lose points, and bubbles reaching the top count as misses. Speed increases every 10 pops. The game ends at the miss limit.

02
KeyMagnet

Type the displayed target key to earn +10 points. Wrong keys are counted. Easy uses home-row letters; Medium uses A–Z and a 5-second limit; Hard adds numbers and a 3-second limit.

03
Controls

Select a difficulty on the home screen. Restart starts the current mode again; Reset clears the game and returns home. A physical keyboard or the on-screen keys can be used.
